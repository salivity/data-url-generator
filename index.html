Frequently Asked Questions (FAQ)

Everything you need to know about Data URL generation, batch processing, and binary reversal.

1. What is a Data URL and how does it work?▼

A Data URL (defined by RFC 2397) is a URI scheme that allows you to embed small files inline within HTML, CSS, SVG, or JSON documents as a string starting with data: followed by a MIME type, an optional ;base64 indicator, and the encoded file payload.

2. How does the Data URL Reversal tool reconstruct files?▼

The reversal engine parses the data: header to identify the MIME type, character set, and encoding method. It then decodes the Base64 or percent-encoded bytes into an exact Uint8Array binary buffer, computes its CRC-32 checksum, assigns the proper file extension, and renders a live preview.

3. Can I convert multiple files into Data URLs at the same time?▼

Yes. Switch to the Batch Generator & ZIP Export tab and drag and drop any number of files. The tool processes all files asynchronously in memory and displays individual sizes, previews, and copy buttons.

4. What is included when I export a Batch ZIP file?▼

The generated ZIP archive can include individual .dataurl.txt files for each uploaded asset, a structured manifest.json mapping file names to Data URLs, an assets.css stylesheet with ready-to-use CSS variables, a summary.csv report, and a visual catalog.html preview page.

5. Are my files or Data URLs uploaded to any external server?▼

No. All Data URL encoding, batch conversion, binary reversal, and ZIP archive generation happen 100% locally inside your web browser using the HTML5 FileReader API, TypedArrays, and Blob objects. Your data never leaves your device.

6. When should I choose URL-Encoded UTF-8 instead of Base64?▼

Base64 encoding adds roughly 33% size overhead to binary files. For plain text formats like SVG icons, HTML snippets, or JSON payloads, choosing URL-Encoded UTF-8 often produces a smaller, human-readable Data URL that compresses better with Gzip or Brotli.

7. Can the Reversal tool extract Data URLs from raw CSS or HTML code?▼

Yes! You can paste an entire CSS stylesheet, HTML document, or JSON file into the Reversal input box. The parser automatically detects and extracts every embedded data:... URI and decodes each asset into a downloadable file or a single ZIP bundle.

8. Is there a file size limit for Data URLs in modern browsers?▼

Modern evergreen browsers (Chrome, Firefox, Edge, Safari) support Data URLs up to tens or hundreds of megabytes. However, for optimal web performance and caching, inline Data URLs are best suited for icons, favicons, fonts, and assets under 32 KB.

9. How can I embed a generated Data URL as an HTML favicon or PWA icon?▼

In the Single Generator tab, set the Code Snippet Wrapper dropdown to HTML Favicon <link>. It will wrap your encoded image or SVG inside a ready-to-paste <link rel="icon" href="data:..."> element.

10. How does the built-in ZIP exporter work without external dependencies?▼

This tool includes a native PKZIP binary serializer written in pure JavaScript. It calculates IEEE 802.3 CRC-32 checksums, writes Local File Headers and Central Directory records directly into a binary Uint8Array, and triggers an instant browser download.
